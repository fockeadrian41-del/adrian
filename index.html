🔧 CachyOS-Tipps

Nützliche Befehle für dein CachyOS-System.

🔄

System aktualisieren

Aktualisiere dein System und deine installierten Pakete.

sudo pacman -Syu
📦

Programm installieren

Installiere ein Paket direkt über Pacman.

sudo pacman -S paketname
🔍

Paket suchen

Suche nach verfügbaren Paketen in den Repositories.

pacman -Ss suchbegriff
🗑️

Paket entfernen

Entferne ein installiertes Paket.

sudo pacman -R paketname
🧹

Cache aufräumen

Entferne alte Pakete aus dem Pacman-Cache.

sudo pacman -Sc
💻

Systeminformationen

Zeige Informationen über dein System an.

fastfetch
TERMINAL

🐧 Pacman-Grundlagen 

$ sudo pacman -Syu

$ sudo pacman -S firefox

$ pacman -Ss firefox

$ sudo pacman -R firefox
